# Puff Slayers art concepts

The 44 PNGs in this folder cover the deliverables in [art-prompts.md](../../docs/art-prompts.md). They were made with the built-in imagegen tool using the style and negative prompts in that document. The existing [vertical battle key visual](../idle-battle-key-visual.png) was used as the style reference and copied to `key-visuals/idle-battle-mobile.png` for a complete set in one folder.

| Folder | PNGs | Content |
|---|---:|---|
| `key-visuals/` | 3 | Vertical battle, desktop battle, ultimate cut-in |
| `characters/` | 18 | Bunbun, Hamham and Shibu across all six classes |
| `enemies/` | 2 | Flower monster sheet and Queen Rafflesia |
| `vfx/` | 8 | Four-stage skill and status effect sheets |
| `items/` | 2 | 4×4 icon sheet and seven rarity frames |
| `backgrounds/` | 6 | Chapter battlefields with diagonal walkable lanes |
| `modes/` | 3 | Puff Pond, co-op raid and PvP arena |
| `branding/` | 2 | Logo and app icon |

Quick reviews: [character contact sheet](overview-characters.jpg) · [other art contact sheet](overview-other.jpg).

The character sheets and VFX sheets are concept references; they have not been separated into individual sprites or animation frames. The PNGs preserve the backgrounds or alpha channels returned by imagegen.
