# Puff Slayers — Game Design Document (v0.2)

> กองทัพสัตว์นุ่มฟูตัวกลมดิ๊ก (กระต่าย · แฮมสเตอร์ · ชิบะ) บุกสวนดอกไม้ ตีมอนสเตอร์ดอกไม้หน้าตาน่าเอ็นดู
> Idle RPG บนเว็บ · เล่นง่าย ปล่อยฟาร์มได้ · ตกปลา · ลงดันกับเพื่อน · PvP

## 0. Player Motivation — ทำไมต้องเล่น

> **"เลี้ยงกองทัพพัฟ ที่ปลุกโลกดอกไม้ให้กลับมาสดใส — แม้ตอนคุณหลับ"**

### 0.1 กลุ่มผู้เล่น: ทุกเพศทุกวัย
| ข้อกำหนด | สิ่งที่ต้องทำในเกม |
|---|---|
| เด็กเล่นได้ | ไม่มีเลือด/ความตาย (Bonk แทน Kill, ฮีโร่แพ้ = "งีบ"), อ่านง่าย ใช้ไอคอนเยอะ, เล่นได้ด้วยนิ้วเดียว |
| ผู้ใหญ่ไม่เบื่อ | จัดทีม/ธาตุ/เผ่าที่มีความลึก, บอสยักษ์ที่ต้องวางแผน, สะสมครบยาก, Arena |
| ผู้สูงวัย/คนไม่ถนัดเกม | Auto ทุกอย่าง, ไม่มีการลงโทษเมื่อแพ้, ตัวอักษรใหญ่ปรับได้, โหมดลดเอฟเฟกต์/ภาพเคลื่อนไหว |
| ปลอดภัยต่อกระเป๋าเงิน | อัตรากาชาแสดงชัด + Pity, **ไม่มีฮีโร่ที่ได้จากเงินเท่านั้น**, จำกัดยอดเติมต่อเดือนสำหรับผู้เยาว์, ไม่บังคับดูโฆษณา |

### 0.2 เรื่องหลัก: สวนที่ถูกสาป (The Grumpy Bloom)
ราชินี **Rafflesia** สาปดอกไม้ทั้งอาณาจักรให้ขี้หงุดหงิดและลุกขึ้นมาอาละวาด
เหล่าพัฟออกเดินทาง **Bonk** ดอกไม้ให้หายงอน → ดอกไม้กลายเป็น **เมล็ด** → นำกลับไป **ปลูกคืนในสวน**
- ทุกการต่อสู้มีความหมาย — ไม่ใช่การฆ่า แต่คือการ "ช่วย" ดอกไม้
- ความคืบหน้าเห็นเป็นภาพ: **แผนที่โลกค่อยๆ กลับมามีสี** และ **สวนที่บ้านโตขึ้นจริง**
- บอสแต่ละ Chapter คือดอกไม้ที่ถูกสาปหนักที่สุด — ช่วยสำเร็จแล้วกลายเป็นเพื่อน (ปลดล็อกของตกแต่ง/เรื่องราว)

### 0.3 แรงจูงใจ 6 ชั้น
| แรงจูงใจ | ทำไมคนเล่น | ระบบที่ตอบ |
|---|---|---|
| **สะสม** (หลัก) | ของน่ารักอยากมีครบ | 18 พัฟ (3 เผ่า × 6 อาชีพ) + สีหายาก, สมุดสะสมเห็นเงาตัวที่ยังไม่มี, Fishdex, ของตกแต่งสวน |
| **โตขึ้น** | เห็นตัวเลข/โลกดีขึ้นทุกวัน | เลเวล/ดาว/ของ 7 Tier, รางวัลตอนหลับ, **กำแพงบอส** (ดูเลเวลแนะนำ), แผนที่ที่กลับมามีสี |
| **ช่วงเวลาอลังการ** | รางวัลเป็นความรู้สึก | Cut-in ท่าไม้ตาย, บอสยักษ์ ENRAGED, เปิดแคปซูลกาชา |
| **ผูกพัน** | รักตัวละครแล้วไม่ทิ้ง | ตั้งชื่อเอง, Bond ปลดบทพูด, ลูบหัว, พัฟนอนกองกันตอนเราไม่อยู่ |
| **เล่นด้วยกัน** | ช่วยเพื่อนและอวด | Co-op Raid, กิลด์, เยี่ยมสวนเพื่อน, การ์ดแชร์ตอนได้ของหายาก |
| **พักผ่อน** | เล่นแล้วไม่เครียด | ตกปลา, แต่งสวน, ไม่มีบทลงโทษ |

### 0.4 วงจรการกลับมาเล่น
| รอบ | ทำอะไร | รู้สึกอย่างไร |
|---|---|---|
| 30 วินาที | ดูพัฟ Bonk ดอกไม้ ท่าไม้ตายปล่อย | เพลินตา |
| 1 Session (3–10 นาที) | เก็บของตอนหลับ → อัปทีม → ปลูกเมล็ด → ผ่านด่านที่ติด | "เก่งขึ้นแล้ว" |
| รายวัน | ภารกิจ, สุ่มแคปซูลฟรี 1 ครั้ง, ตกปลา, รดน้ำสวน, ส่งหัวใจ | มีเรื่องให้กลับมาเช็ก |
| รายสัปดาห์ | บอสยักษ์, Raid กับเพื่อน, อันดับ Arena, ปลาทองสุดสัปดาห์ | เป้าหมายใหญ่ได้อวด |
| ระยะยาว | ปลุกสวนครบทุก Chapter, สะสมพัฟครบ, จบ Season | ภูมิใจ ทิ้งไม่ลง |

### 0.5 สวนปลุกโลก (Garden Restoration) — ระบบเอกลักษณ์
- **เมล็ด** ได้จากการ Bonk (ชนิดเมล็ด = ชนิดดอกไม้ที่ช่วย) → ปลูกในแปลงที่บ้าน
- ดอกที่บาน: ให้ **บัฟถาวรเล็กๆ** (เช่น ดอกเดซี่ครบ 10 ต้น = HP ทีม +1%) และเป็นของตกแต่ง
- แต่ละ Chapter มี **% การฟื้นฟู** (Bonk + ปลูก + ชนะบอส) — ครบ 100% แผนที่ Chapter นั้นกลับเป็นสีสดถาวร + รางวัลใหญ่
- เพื่อนมาเยี่ยม **รดน้ำให้กันได้** (ได้ Friendship Pt ทั้งสองฝ่าย)

### 0.6 ลำดับสิ่งที่ต้องทำก่อน (ผลต่อ Retention)
1. **รางวัลตอนหลับ + อัปเลเวลฮีโร่ด้วย Petal** — ตอนนี้ Petal เก็บได้แต่ยังใช้ไม่ได้
2. **สวนปลุกโลก** (ข้อ 0.5) — เอกลักษณ์ของเกม
3. **สมุดสะสม + 3 ทางได้พัฟ** (ข้อ 13.1: กาชา / ฟาร์ม / ตกปลา)
4. ภารกิจรายวัน + ตกปลา
5. Co-op Raid + Arena

## 1. Game Pillars (หลักที่ทุกฟีเจอร์ต้องตอบ)

| # | Pillar | ความหมายในเชิงออกแบบ |
|---|--------|------------------------|
| 1 | **Squishy Cute** | ทุกอย่างต้อง "อยากบีบ" — ตัวละครเด้งดึ๋ง, ปุ่มยุบได้, ศัตรูโดนตีแล้วงอน ไม่ตาย (กลายเป็นเมล็ดพันธุ์ปลิวไป) |
| 2 | **Zero Friction** | เปิดเกมมาไม่เกิน 3 แตะก็ได้ของ ทุกระบบมีปุ่ม Auto / Claim All |
| 3 | **Idle but Meaningful** | ปล่อยฟาร์มได้ แต่การจัดทีม/เลือกอาชีพ/เลือกอุปกรณ์ต้องมีผลชัดเจน |
| 4 | **Better Together** | ของที่ดีที่สุดมาจากการเล่นกับเพื่อน (Co-op Raid) ไม่ใช่การเติมเงิน |

**Tone:** ไม่มีความรุนแรง — ดอกไม้โดนตีแล้ว "เหี่ยวงอน → กลายเป็นเมล็ด → ปลิวกลับไปปลูกใหม่" ใช้คำว่า *Bonk* แทน Kill

## 2. Core Loop

```
          ┌──────────── ปล่อยฟาร์ม (Idle / Offline) ────────────┐
          ▼                                                     │
  [Stage Auto-Battle] ──► ได้ Petal Coin, EXP, Item, Seed ──► [อัปเกรดฮีโร่/ของ]
          │                         │                           ▲
          │                         └──► [ปลูกเมล็ดในสวน] ──► บัฟถาวร + แผนที่กลับมามีสี
          │                                                     ▲
          ├──► เจอ Boss Gate ตัน ──► ไปตกปลา (Food Buff) ─────────┤
          ├──► ลง Co-op Dungeon กับเพื่อน (วัสดุ Tier สูง) ────────┤
          └──► Arena PvP (อันดับ + Cosmetic + Honor Shop) ───────┘
```

- **Session สั้น (1–3 นาที):** เก็บรางวัล Offline → อัปเกรด → กดผ่านบอส → ออก
- **Session กลาง (10–20 นาที):** ตกปลา / Arena 5 ตา / Daily Dungeon
- **Session ยาว (30+ นาที):** Co-op Raid กับเพื่อน, จัดทีม PvP ใหม่

## 3. ตัวละคร: เผ่า (Species) × อาชีพ (Class)

ฮีโร่ทุกตัว = **เผ่า 1 เผ่า + อาชีพ 1 อาชีพ** → เผ่าให้ Passive, อาชีพให้บทบาท/สกิล
ทำให้ได้ฮีโร่เยอะโดยงานอาร์ตคุมได้ (ร่างเดียวกัน เปลี่ยนชุด/อาวุธ/หมวก)

### 3.1 เผ่า (Species)

| เผ่า | รูปทรง | Passive เผ่า | บุคลิก |
|------|--------|--------------|--------|
| 🐰 **Bunbun** (กระต่าย) | กลมยาว หูเด้ง | **Hop Dodge** — หลบ +8%, หลบสำเร็จแล้วเร่ง ATK SPD 2 วิ | ขี้ตกใจ แต่ไวสุด |
| 🐹 **Hamham** (แฮมสเตอร์) | กลมดิ๊ก แก้มป่อง | **Cheek Pouch** — Drop Rate +5%, HP +10% | ตะกละ เก็บทุกอย่างใส่แก้ม |
| 🐕 **Shibu** (ชิบะ) | ก้อนขนมปังมีหาง | **Doge Pride** — Crit +8%, คริแล้วสะสม "Much Wow" 1 สแตก (สูงสุด 5 → ATK +10%) | มั่นใจเกินตัว |
| 🦭 *Mochi Seal* (อนาคต) | ก้อนโมจิ | ฮีลที่ได้รับ +15% | ง่วงตลอด |
| 🐥 *Puffchick* (อนาคต) | ลูกไก่ขนฟู | เริ่มต่อสู้ได้ Shield | ร่าเริงเสียงดัง |

**Species Synergy** (ใส่เผ่าเดียวกันในทีม):
- 2 ตัว: โบนัสเล็ก (เช่น Bunbun ×2 = SPD +5%)
- 3 ตัว: โบนัสกลาง + เอฟเฟกต์ภาพ (หูตั้งพร้อมกัน, แก้มป่องพร้อมกัน)
- 5 ตัว (ทีมเผ่าเดียว): "Fluff Parade" — ท่าเต้นเปิดฉาก + บัฟใหญ่

### 3.2 อาชีพ (Class) — 6 อาชีพตอนเปิดตัว

| อาชีพ | บทบาท | อาวุธน่ารัก | ตำแหน่ง | กลไกเด่น |
|-------|--------|-------------|----------|-----------|
| 🛡️ **Pillow Guard** | Tank | หมอนยักษ์ + ฝาหม้อ | แถวหน้า | Taunt, Shield, สะท้อนดาเมจเป็นขนนก |
| ⚔️ **Carrot Knight** | Melee DPS | ดาบแครอท / ค้อนแตงกวา | แถวหน้า | Combo stack, Cleave |
| 🏹 **Seed Sniper** | Ranged DPS | หนังสติ๊กยิงเมล็ดทานตะวัน | แถวหลัง | Single-target burst, Mark |
| 🫧 **Bubble Mage** | AoE Magic | ไม้เป่าฟองสบู่ | แถวหลัง | AoE, Soaked (ลด DEF), ธาตุ |
| 🍡 **Mochi Cleric** | Healer | ไม้เสียบดังโงะ | แถวหลัง | ฮีล, Cleanse, ชุบชีวิต 1 ครั้ง |
| 🔔 **Bell Bard** | Buff/Debuff | กระดิ่ง + กลองแพนเค้ก | กลาง | บัฟ ATK SPD, Sleepy (หลับ), Energy Charge |

**Class Advance (เปลี่ยนอาชีพขั้น 2)** ที่ Lv.60 เลือก 1 ใน 2 สาย เช่น
- Pillow Guard → **Fortress Futon** (แทงก์ล้วน) / **Cushion Crusher** (แทงก์ตีแรง)
- Bubble Mage → **Foam Sorcerer** (AoE) / **Soap Witch** (Debuff)
- Mochi Cleric → **Dango Saint** (ฮีลหนัก) / **Sugar Shaman** (ฮีล + โล่)

## 4. ระบบต่อสู้ & Skill Effects

### 4.1 รูปแบบการต่อสู้ (Real-time, เคลื่อนที่อิสระ)
- **ไม่ใช่ turn-based / ไม่ยืนประจำช่อง** — ทุกตัวเดินได้รอบทิศบนสนามทุ่งดอกไม้
- ทีม 5 ตัวเกาะกลุ่มแบบหลวมๆ ศัตรูโผล่จากขอบสนามหลายทิศทาง (คลื่นละ 5–7 ตัว)
- สายประชิดวิ่งเข้าหาเป้าที่ใกล้สุด, สายไกลรักษาระยะและถอยเมื่อโดนประชิด (kite), ทุกตัวดันกันไม่ให้ซ้อน
- Pillow Guard ยั่วศัตรูที่อยู่ในรัศมี, Carrot Knight ใช้ Ultimate แล้วพุ่ง (dash) เข้าหาเป้า
- Ultimate สไตล์อนิเมะ: หรี่จอ + cut-in + speed lines + วงเวทย์ + เสาแสง + shockwave + zoom blur + hitstop
- Auto-attack ตลอด, **Skill 1** ใช้อัตโนมัติตาม Cooldown, **Ultimate** ใช้เมื่อ Energy เต็ม (Auto หรือกดเองก็ได้)
- ความเร็วเกม ×1 / ×2 / ×3 (×3 ปลดล็อกที่ Chapter 3)

### 4.2 ธาตุดอกไม้ (สามเหลี่ยม + 2 พิเศษ)

```
      ☀️ Sun ──ชนะ──► 🍃 Leaf
        ▲                │
       ชนะ              ชนะ
        │                ▼
      💧 Dew ◄──────────┘
  🌙 Moon ⇄ 🌟 Star  (แพ้ทางกันเอง, โผล่ในด่านท้าย/Raid)
```
ชนะทาง = ดาเมจ +30%, แพ้ทาง = -20% — ศัตรูแต่ละด่านมีธาตุเด่น ทำให้ต้องเปลี่ยนทีมบ้าง (มี **Auto-Team** แนะนำให้)

### 4.3 สถานะ (Status Effects) — ตั้งชื่อน่ารักแต่เข้าใจง่าย

| สถานะ | ผล | ภาพ |
|--------|-----|------|
| **Sticky** (น้ำผึ้ง) | ช้าลง 30% | หยดน้ำผึ้งเยิ้ม |
| **Sleepy** | หยุด 2 วิ, โดนตีแล้วตื่น | Zzz + ฟองน้ำมูก |
| **Tickled** | Stun 1 วิ | ขนนกจั๊กจี้ ศัตรูหัวเราะ |
| **Soaked** | DEF -20% | ตัวเปียกหยดน้ำ |
| **Pollen** | ดาเมจต่อเนื่อง | ละอองเหลืองจาม |
| **Sparkle Mark** | รับคริแรงขึ้น 25% | ดาวกระพริบบนหัว |
| **Grumpy** (ศัตรูใช้) | ATK ลดลง | เมฆฝนเล็กบนหัว |

### 4.4 Skill Effect Language (ให้ทีมอาร์ตใช้เป็นกติกา)
- **ทุกดาเมจตัวเลขเด้งเป็นฟอนต์กลม** + คริเป็นรูปหัวใจแตก ✦
- เอฟเฟกต์ใช้ของใช้/ขนม: ขนนก, ฟองสบู่, เมล็ดพืช, ลูกกวาด, ผ้าห่ม, มาชเมลโล่
- **Ultimate = Cut-in** ครึ่งจอ ตัวละครทำหน้าจริงจัง (ตลกเพราะตัวกลม) 0.8 วิ แล้วค่อยปล่อยท่า
- ตัวอย่าง Ultimate:
  - **Pudding — "Ultimate Roll"**: ม้วนตัวเป็นบอลกลิ้งทับทั้งแถว ทิ้งรอยขนฟู
  - **Daifuku — "Bubble Bye-bye"**: ขังศัตรูในฟองลอยขึ้นฟ้า แตกเป็นกลิตเตอร์
  - **Tofu — "Carrot Crescent"**: ฟันแครอทเป็นวงพระจันทร์ เศษแครอทปลิว
  - **Kuma-Shiba — "Bear Hug Festival"**: ทีมทั้งหมดเต้น บัฟ ATK +40% 8 วิ
- **Puff Chain:** ใช้ Ultimate ต่อกันภายใน 1.5 วิ → โบนัสดาเมจ +10%/ต่อ และขึ้นตัวหนังสือ "Fluffy ×3!" (ให้คนที่กดเองได้เปรียบเล็กน้อย แต่ Auto ก็ทำได้)

### 4.5 ค่าสถานะ
`HP · ATK · DEF · SPD (ATK SPD) · CRIT% · CRIT DMG · DODGE · LUCK · HEAL POWER · ENERGY REGEN`
**LUCK** ส่งผลกับ Drop Rate โดยตรง (ดูข้อ 6) — ให้ผู้เล่นเลือกได้ว่าจะจัดทีม "ฟาร์ม" หรือ "ตี"

### 6.10 UX กระเป๋า (ต้องเล่นง่าย)
- ปุ่ม **"ใส่ของดีที่สุด"** ต่อฮีโร่และทั้งทีม · **Auto-Merge** · **Auto-แยก** Tier ต่ำกว่าที่ตั้งไว้

### 6.11 สูตร Drop Rate (ปรับได้จากฝั่งเซิร์ฟเวอร์)

```
FinalRate(tier) = BaseRate(tier, stageBand)
                × (1 + LuckBonus + SpeciesBonus + EventBonus + PartyBonus)
                capped at MaxRate(tier)
```

**BaseRate ตั้งต้น (ต่อการ Bonk ศัตรู 1 ตัว / 1 Drop Roll)**

| Tier | Ch.1–2 | Ch.3–4 | Ch.5–6 | Co-op Raid (ต่อการเคลียร์) |
|------|--------|--------|--------|------------------------------|
| Crumb | 60% | 40% | 20% | — |
| Fluffy | 30% | 38% | 35% | 20% |
| Silky | 9% | 17% | 30% | 45% |
| Dreamy | 0.9% | 4.5% | 12% | 25% |
| Starry | 0.1% | 0.45% | 2.5% | 8% |
| Mythic Puff | 0% | 0.05% | 0.5% | 1.8% |
| Cosmic Cotton | 0% | 0% | 0% | 0.2% |

- **LuckBonus** = LUCK / (LUCK + 1000) — มีผลตอบแทนลดลง (diminishing) กันเลขพัง
- **Hamham Cheek Pouch** = +5% ต่อตัวในทีม (สูงสุด 3 ตัว)
- **PartyBonus** (Co-op): +10% ต่อเพื่อนในปาร์ตี้ +5% ถ้าเป็นเพื่อนในลิสต์
- **Pity System:** ไม่ได้ Starry+ ครบ N ครั้ง → การันตี (ตัวนับแสดงในหน้า UI ให้เห็นชัด — โปร่งใส)
- **Offline Drop** = คำนวณจาก Expected Value ไม่ใช่สุ่มทีละตัว (เบาเซิร์ฟเวอร์) แต่ยังสุ่ม Starry+ จริงเป็นก้อน
- ค่าทั้งหมดเก็บใน `drop_tables` (JSON/DB) → **Live Tuning** ผ่าน Admin Panel ได้ทันที, ทุกการเปลี่ยนมี version + log
- หน้า **"Drop Info"** ในเกมแสดงอัตราจริงทุกด่าน (โปร่งใส, ถูกกฎหมายหลายประเทศ)

## 8. Mini Mode: ตกปลา 🎣 "Puff Pond"

### 8.1 การเล่น (Active)
1. **Cast:** แตะค้างแล้วปล่อย — แถบพลังเด้งไปมา ปล่อยตรงโซนทอง = ปลาหายากขึ้น
2. **Wait:** ทุ่นลอย มีทุ่นหลอก (ใบไม้ตกน้ำ) — กดตอนปลากินจริง
3. **Reel:** มินิเกม "Tension" — กดค้างให้ตัวชี้อยู่ในโซนเขียว ปลาดิ้นซ้าย/ขวา (10–20 วิ)
4. ได้ปลา → ตัวละครชูปลาขึ้นฟ้า + ท่าดีใจตามเผ่า (Shibu ทำหน้า "Much Wow")

### 8.2 Auto-Fish (Idle)
- ส่งฮีโร่ที่ไม่ได้อยู่ในทีมไปนั่งตกปลา → ได้ปลาธรรมดาต่อชั่วโมง (ปลาหายากต้องตกเองเท่านั้น → มีเหตุผลให้เล่น Active)

### 8.3 ระบบรอบๆ
| ส่วน | รายละเอียด |
|------|-------------|
| **จุดตกปลา** | บ่อหลังบ้าน → ทะเลสาบบัว → ทะเลนม → สระดาว (ปลดตาม Chapter) |

## 10. PvP: "Pillow Fight Arena" 🪶

### 10.1 Async Arena (หลัก — เหมาะกับ Idle)
- ตั้ง **ทีมป้องกัน** ไว้ → ผู้เล่นอื่นมาท้าตี (AI เล่นทีมเรา)
- เลือกคู่ต่อสู้จาก 3 คน (ง่าย/กลาง/ยาก) วันละ 5 ครั้งฟรี
- ผลการต่อสู้คำนวณด้วย **Deterministic Simulation บนเซิร์ฟเวอร์** (Seed เดียวกัน = ผลเดียวกัน ⇒ Replay ได้ + กันโกง)
- **Rank:** Cotton → Wool → Silk → Cashmere → Cloud → **Legend Puff** (รีเซ็ตทุก Season 4 สัปดาห์)

### 10.2 Real-time "Pillow Duel" (รอง — เปิดสุดสัปดาห์)
- 1v1 แบบ **Draft**: ผลัดกันแบน/เลือกฮีโร่
- **Normalized Stats** — ทุกตัวเลเวล/ของเท่ากัน ⇒ วัดกันที่การจัดทีม+จังหวะ Ultimate (แฟร์ ไม่ P2W)
- 1 แมตช์ ~2–3 นาที

### 10.3 รางวัล PvP
Honor Coin → ร้าน Cosmetic, กรอบโปรไฟล์, ท่าเต้นชนะ, สกินหมอน — **ไม่ขายพลังจาก PvP**

| สกุลเงิน | ได้จาก | ใช้กับ |
|-----------|---------|---------|

| 🐟 **Fish Scale** | ตกปลา | ร้านตกปลา, อาหาร |
| ✨ **Stardust** | แยกอุปกรณ์ | สุ่ม substat ใหม่, ตีบวก |
| 💖 **Friendship Pt** | Co-op, ส่งหัวใจ | ร้านเพื่อน |
| 🪶 **Honor** | PvP | ร้าน Cosmetic PvP |

**ฮีโร่:** Level (1–100+) → Star (★3–★6, ใช้ Seed/ตัวซ้ำ) → Class Advance (Lv.60) → **Bond** (ใช้งานด้วยกันบ่อย ปลดเสียงพูด/สตอรี่เล็ก)

### 13.1 วิธีได้พัฟ — 3 ทาง (ทุกตัวได้ฟรีจากการเล่น)
| ทาง | รายละเอียด | บทบาท |
|---|---|---|
| **🥚 Puff Capsule (กาชา)** | ตู้แคปซูลไข่ ใช้ Dew Drop (ได้จากเล่น/เควส/เติม) — สุ่มฟรีวันละ 1 ครั้ง | เร็ว ตื่นเต้น |
| **🌾 ฟาร์ม** | บอสแต่ละด่านดรอป **ชิ้นส่วนพัฟ** (Puff Shard) ของตัวประจำ Chapter — ครบ 50 ชิ้น = ปลดล็อก, ตัวซ้ำ = อัปดาว | แน่นอน ช้าแต่ชัวร์ |
| **🎣 ตกปลา** | ปลาหายากแลก **Fish Scale** → ร้านตกปลามีพัฟหมุนเวียนรายสัปดาห์ + สีพิเศษ (เช่น พัฟลายปลาคาร์ป) | ทางผ่อนคลาย, ตัวพิเศษเฉพาะทาง |

**กติกากาชา (เหมาะทุกวัย):**
| ระดับ | อัตรา | Pity |
|---|---|---|
| ★3 | 79% | — |
| ★4 | 18% | การันตี ★4+ ทุก 10 ครั้ง |
| ★5 | 2.7% | การันตี ★5 ภายใน 60 ครั้ง |
| ★6 | 0.3% | ครบ 150 ครั้ง **เลือกตัว ★6 ได้เอง** (spark) |
- แสดงอัตราและตัวนับ Pity บนหน้าตู้เสมอ, ตัว Pity ไม่รีเซ็ตข้ามแบนเนอร์
- ตัวซ้ำ → Puff Shard (ใช้อัปดาว) ไม่มีสูญเปล่า
- ไม่มีพัฟที่ได้จากกาชาอย่างเดียว — ทุกตัวได้จากฟาร์มหรือตกปลาด้วยเสมอ (ช้ากว่า)
- บัญชีผู้เยาว์: จำกัดยอดเติมต่อเดือน + ต้องยืนยันผู้ปกครอง

**Monetization (แนวทาง fair):** Battle Pass, Cosmetic (สกิน/หมวก/ท่าเต้น), Nap Bank ขยาย, Starter Pack
เลี่ยง: ขาย Mythic ตรงๆ, ขาย PvP power, Pay-to-skip Co-op

## 14. สถาปัตยกรรมทางเทคนิค (Web)

```
┌──────────── Client (Browser) ─────────────┐
│ Vite + TypeScript                          │
│  ├─ UI Layer: React (หรือ Svelte)          │
│  ├─ Battle Renderer: PixiJS v8 (WebGL)     │
│  │   └─ Particle/FX: @pixi/particle-emitter│
│  └─ @puff/sim  ← ใช้ร่วมกับ Server          │
└───────────────┬────────────────────────────┘
       REST (HTTPS)  │  WebSocket
┌───────────────▼────────────────────────────┐
│ Server (Node.js + TypeScript)              │
│  ├─ API: Fastify (บัญชี, คลัง, ร้าน, Idle)  │
│  ├─ Realtime: Colyseus (Co-op, PvP Duel)   │
│  ├─ @puff/sim (Deterministic Combat)       │
│  └─ Workers: คำนวณ Offline, Season reset   │
├────────────────────────────────────────────┤
│ PostgreSQL (ข้อมูลถาวร) · Redis (Session,  │
│ Leaderboard, Matchmaking) · S3/CDN (Asset) │
└────────────────────────────────────────────┘
```

**หลักการสำคัญ**
1. **Shared Deterministic Sim (`packages/sim`)** — ระบบต่อสู้เขียนครั้งเดียว ใช้ทั้ง Client (แสดงผล) และ Server (ตัดสินผล) ใช้ Seeded RNG + Fixed Timestep → PvP/Co-op/Offline ตรวจสอบได้, Replay ได้
2. **Server-Authoritative** — Drop, สกุลเงิน, ผลการต่อสู้ ตัดสินที่เซิร์ฟเวอร์เท่านั้น (Client แค่ขอ "Claim")
3. **Offline = คำนวณแบบ EV** จากเวลาที่ผ่านไป × อัตราฟาร์มของทีม (ไม่จำลองทีละวินาที)
4. **Data-driven** — ฮีโร่/สกิล/Drop Table/ด่าน อยู่ใน JSON Schema (validate ด้วย Zod) แก้ได้โดยไม่ Deploy โค้ด
5. **Asset Pipeline** — Sprite Sheet + Skeletal animation (Spine หากมีงบ license / ทางเลือกฟรี: DragonBones หรือ Rive) · PWA ติดตั้งลงมือถือได้

**โครงสร้าง Monorepo (pnpm workspaces)**
```
PuffSlayers/
├─ apps/
│  ├─ web/          # Client
│  ├─ server/       # API + Colyseus
│  └─ admin/        # Live tuning, Drop table, Event
├─ packages/
│  ├─ sim/          # Deterministic combat + tests
│  ├─ data/         # heroes, skills, stages, drop tables (JSON + Zod)
│  └─ shared/       # types, constants, protocol
└─ docs/
   └─ GDD.md
```
